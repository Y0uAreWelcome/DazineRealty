# Dazine Realty — Site Map & Integrations Plan

## Third-party integrations

| Service | What the code uses it for | Where |
|---|---|---|
| **Google Analytics 4** | Loads Google’s `gtag.js` and configures measurement ID `G-FYJN9053RN` on the HTML pages. | `index.html`, `blog.html`, `testimonials.html`, `legal.html` |
| **WidgetTracker / widgetbe.com** | Sends a pageview using tracker ID `WT-IHWDWRTC`. The code is on the home page only. | `index.html` |
| **Airtable** | Hosts the embedded contact form in an iframe. Form submission is handled by Airtable, not by a server in this repository. | `index.html` |
| **Klaviyo** | Loads the Klaviyo onsite JavaScript and its initialization code on the pages. The HTML doesn’t show a specific signup form or campaign setup; any onsite features may be configured in the Klaviyo account. | `index.html`, `blog.html`, `testimonials.html`, `legal.html` |
| **Google Fonts** | Loads the Inter typeface. | All pages |
| **Unsplash** | Supplies the home hero’s background photo. | `style.css` |
| **GitHub Pages and GitHub Actions** | On a push to `main`, the workflow publishes the repository files to the `gh-pages` branch. | `.github/workflows/pages.yml` |

The home page also links out to **Instagram, LinkedIn, YouTube, Zillow, and Yelp**. These are ordinary outbound profile links, not embedded APIs or plugins. The footer links to **Intero Real Estate Services**; its logo is a local image. The profile and footer links are in `index.html`.

The site describes Matterport tours, drone photography, and FPV media as services, but there is no corresponding Matterport integration or embedded MLS/listings feed in the code. The listings section is part of the home page rather than a separate listings app.

## Site plan / sitemap

```text
/
└── index.html — Home page
    ├── #about      About Dazine Realty
    ├── #services   Services
    ├── #listings   Listings section
    └── #contact    Airtable form, contact details, and social links

├── blog.html         Static blog articles
├── testimonials.html Client testimonials page
└── legal.html
    ├── #privacy
    └── #terms
```

Navigation and the home-page sections are in `index.html`; the other pages are `blog.html`, `testimonials.html`, and `legal.html`. The pages share `style.css` and local image assets.

**In practical terms:** this is a static HTML/CSS site deployed by GitHub Actions. It has no application server or local database; Airtable provides the contact form, while the analytics and marketing scripts run through their respective external services.
